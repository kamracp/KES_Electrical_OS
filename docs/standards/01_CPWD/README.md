## Use rules

- CPWD text is a national specification and outranks IEC guidance in the project precedence
  order (see the master reference register); it never outranks statutory CEA requirements or
  the approved project design basis.
- No table value from these documents enters a calculation engine until the specific table,
  clause and edition are recorded in the reference data layer with this checksum, and the
  mapping has passed independent engineering review.
- Chapter titles above are reproduced for navigation only; clause text is not copied into the
  repository.
